## 🚀 Featured project

### ♟️ [Chess](https://github.com/David-Varg/Chess)

A chess engine built from scratch in Java, designed around **Hexagonal Architecture (Ports & Adapters)**.

- Implements legal move generation and special moves, including castling, en passant, and promotion.
- Detects checkmate, stalemate, and draw conditions.
- Keeps the domain independent from input/output concerns.
- Uses OOP and SOLID principles to keep the code organized and testable.

[Explore the repository →](https://github.com/David-Varg/Chess)
